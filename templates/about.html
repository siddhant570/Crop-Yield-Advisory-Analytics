About Project — Crop Yield Advisory Analytics

College Mini-Project Technical Overview, Review 1 Scope, Dataset Dictionary, and Architecture.

Problem Statement & Course Alignment

"Farmers often find it difficult to understand how factors such as soil conditions, rainfall, temperature, fertilizer usage, and irrigation affect crop yield. The proposed system analyzes agricultural data and presents useful insights through analytics and visualizations to support better crop-related decisions."

Pipeline Workflow:

Data Collection → Data Cleaning → Agricultural Database → Statistical Analysis → Crop Yield Analysis → Visualization → Advisory Recommendations

"The collected agricultural data will first be cleaned and prepared. Important variables will then be analysed using statistical techniques and visualizations. The final results will be presented as understandable crop-yield insights."

Problem Mapping with Foundational Courses:

  • Python — Data processing, cleaning, and analysis
  • DBMS — Relational dataset storage and management (MySQL / SQLite fallback)
  • Statistics — Descriptive analysis and bivariate Pearson correlation of agricultural factors
  • Data Visualization — Graphs, charts, and executive dashboards (Chart.js)
  • Web/Software Development — User interface and system integration (Flask Web Framework)
Prototype Disclaimer: This application is an academic analytics prototype developed for a 2nd-year B.Tech AI & Data Science mini-project. It does not claim to provide scientifically validated farming advice.

Dataset Attribute Dictionary

Field Name Data Type Unit / Format Description
id INT / AUTO_INCREMENT Numeric Key Unique identifier for agricultural record
crop_type VARCHAR(50) Categorical Type of cultivated crop (e.g. Rice, Wheat, Maize, Cotton, Sugarcane, Pulses)
soil VARCHAR(50) Categorical Soil classification (Alluvial, Black, Red, Clay, Loam)
rainfall FLOAT Millimeters (mm) Seasonal precipitation / rainfall volume
temperature FLOAT Degrees Celsius (°C) Average seasonal ambient temperature
fertilizer FLOAT kg/hectare (kg/ha) Chemical / organic fertilizer input applied per hectare
irrigation VARCHAR(50) Categorical Primary irrigation technique (Canal, Drip, Tube Well, Rainfed)
yield_value FLOAT tons/hectare (tons/ha) Total crop yield output per hectare
location VARCHAR(100) Geographic State Agricultural region / State location in India
season VARCHAR(50) Cropping Season Agricultural season (Kharif, Rabi, Zaid)
